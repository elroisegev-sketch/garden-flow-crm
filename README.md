# Travel Vault

ארנק נסיעות לאייפון. המסמכים, הכרטיסים והפרטים נשמרים במכשיר ונפתחים גם בלי אינטרנט.

```bash
npm install
npm run dev
```

ואז פותחים את האפליקציה בטלפון, ומוסיפים למסך הבית: שיתוף ← הוספה למסך הבית.

טיול הדמו הוא וינה, 04.10.2026–08.10.2026, לאלרואי וליאור. כל השדות ניתנים לעריכה, ואפשר לפתוח טיולים נוספים מההגדרות.
